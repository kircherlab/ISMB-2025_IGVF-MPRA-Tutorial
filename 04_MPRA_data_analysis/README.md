# BCalm MPRA Analysis Tutorial

Hands-on tutorial for analyzing Massively Parallel Reporter Assay (MPRA) data using the BCalm R package. This tutorial covers both element activity analysis and variant effect quantification.

## Overview

In this session we will:
- Understand linear models and their usage in MPRA analysis
- **Analyze regulatory element activity** compared to negative controls
- **Quantify genetic variant effects** on gene regulation


## Dataset

We use a subset HepG2 cell line MPRA data which is the output of th previous analysis. All datasets that is used in this tutorial is available at https://github.com/kircherlab/ISMB-2025_IGVF-MPRA-Tutorial/edit/main/04_MPRA_data_analysis/.
